# Конференции.РФ

Студенческий проект - Информационная система для регистрации, отслеживания и организации научных и бизнес-конференций.

# 🛠 Технологический стек
* Node.js - основа структуры , вся логика там 
* Express - аналог популярного PHP
* SQLite - для создания портативной БД
* EJS - Шаблоны страниц сайта
* Bootstrap - Стилизация и готовые CSS шаблоны

```text
conferences_rf/
│
├── 📄 package.json                    ← зависимости и скрипты запуска
├── 📄 package-lock.json               ← фиксация версий пакетов
├── 📄 .gitignore                      ← правила игнорирования файлов для Git
├── 📄 server.js                       ← точка входа, конфигурация сервера и роуты
├── 📄 db.js                           ← логика подключения к БД и CRUD-операции
├── 📄 conf.db                         ← файл базы данных SQLite (генерируется автоматически)
│
├── 📁 views/                          ← шаблоны страниц (EJS)
│   ├── 📄 header.ejs                  ← общий заголовок и навигация
│   ├── 📄 footer.ejs                  ← подвал сайта
│   ├── 📄 auth.ejs                    ← формы регистрации и входа
│   ├── 📄 rooms.ejs                   ← каталог помещений для конференций
│   ├── 📄 requests_list.ejs           ← список заявок пользователя/администратора
│   ├── 📄 create_request.ejs          ← форма подачи новой заявки
│        
│
├── 📁 public/                          ← статические ресурсы
│   ├── 📁 css/
│   │   ├── 📄 bootstrap.min.css     ← стили Bootstrap
│   │   └── 📄 style.css              ← кастомные стили проекта
│   ├── 📁 js/
│       └── 📄 bootstrap.bundle.min.js ← скрипты Bootstrap
│
└── 📁 docs/                           ← документация проекта
    ├── 📄 er_diagram.png              ← ER-диаграмма базы данных
    ├── 📄 schema.sql                  ← SQL-схема таблиц
    └── 📄 README.md                   ← текущий файл документации
```
